# Aarambh — Updated Project

## Added
- Living Heritage experience page at `/living-heritage`
- Artisan / craftspeople story + interview modal
- Interactive Taj Mahal historical timeline
- Heritage AR preview with optional camera access
- Community explorer discoveries with local image upload + likes
- Planner visual refresh using the existing Aarambh cream / forest-green / muted-gold theme
- Responsive styling for planner and new Living Heritage experience

## Run
```bash
npm install
npm run dev
```

Then open the local Vite URL shown in the terminal.

Camera access for the AR demo requires browser permission and normally HTTPS or localhost.
